# JBC Soldering Controller

Контролер паяльної станції на **STM32F103C8T6 (Blue Pill)**: ПІД-регулювання температури жала, вимірювання потужності, кольоровий TFT-дисплей, керування одним енкодером і багаторівневий захист.

Проект — порт на STM32 відомого контролера [timothyjager](https://github.com/timothyjager) (2017, MIT) для Arduino-середовища (ядро STM32duino).

## Можливості

- ПІД-регулювання температури, апаратний ШІМ нагрівача на TIM2 (період 20 мс, 50 Гц).
- Термопара через 16-бітний АЦП **ADS1118** з компенсацією холодного спаю; вибірка синхронізована з ШІМ (у момент, коли нагрівач вимкнений).
- Вимірювання напруги, струму і потужності через **INA219**; додатково аналітичний датчик струму ключа (VN5E CS).
- TFT **ST7735** 160×128: велика температура, шкали потужності та ШІМ, три профілі, відмальовування без мерехтіння.
- Енкодер із кнопкою, датчик підставки (cradle), RGB-індикатор WS2812, пищалка зі звуковою індикацією подій.
- Захист: обрив термопари, перегрів, розгін (runaway), відсутність росту температури, апаратний watchdog 8 с.
- Текстовий UART-протокол для налаштування PID, уставки й звуку та потік телеметрії.
- Збереження уставки, PID і профілів в EEPROM (емуляція у flash).

## Апаратна частина

| Компонент | Призначення |
|---|---|
| STM32F103C8T6 (Blue Pill) | MCU |
| ADS1118 | АЦП термопари + датчик холодного спаю (SPI1) |
| INA219 (I²C, 0x40, шунт 0.0056 Ом) | напруга / струм / потужність |
| Силовий ключ типу VN5E | комутація нагрівача, вихід датчика струму на PB1 |
| ST7735 TFT | дисплей (SPI2) |
| WS2812 | індикатор стану |
| Енкодер з кнопкою | керування |
| Датчик підставки | перехід у STANDBY |
| Пищалка | звукова індикація |

Живлення нагрівача за коментарями в коді розраховане на **24 В**.

### Розпіновка

| Сигнал | Пін | Сигнал | Пін |
|---|---|---|---|
| Нагрівач (ШІМ, TIM2_CH1) | PA0 | Енкодер A / B / кнопка | PB3 / PB4 / PB5 |
| Підсвітка TFT | PA1 | Датчик підставки | PB12 |
| ADS1118 CS | PA4 | WS2812 | PB0 |
| SPI1 SCK / MISO / MOSI | PA5 / PA6 / PA7 | Датчик струму ключа (CS) | PB1 |
| TFT CS / DC / RST | PA8 / PA9 / PA10 | Пищалка | PB8 |
| SPI2 SCK / MISO / MOSI | PB13 / PB14 / PB15 | UART2 TX / RX | PA2 / PA3 |
| I²C SCL / SDA | PB6 / PB7 | | |

> `PB3` і `PB4` — лінії JTAG. У прошивці JTAG вимикається, лишається **SWD**, тому прошивати плату слід через ST-Link.

## Збірка і прошивка

1. Встановіть Arduino IDE з ядром **STM32duino** (`STMicroelectronics:stm32`).
2. Встановіть бібліотеки: *Adafruit GFX Library* (разом з *Adafruit BusIO*), *Adafruit NeoPixel*, *Adafruit INA219*, *PID* (Brett Beauregard, `PID_v1`). Бібліотека ST7735 лежить у `src/Adafruit-ST7735-Library-master/` і підключається автоматично.
3. Назва папки скетча має збігатися з головним файлом: `JBC-Soldering-Controller` (прибрати суфікс `-main`).
4. Плата: Generic STM32F1 series → Generic F103C8, метод завантаження — ST-Link.
5. Скомпілюйте й прошийте. Термінал UART — 230400 бод, 8N1.

## Керування

| Дія | Результат |
|---|---|
| Обертання енкодера | уставка ±1 °C (0…450 °C) |
| Коротке натискання | увімкнути / вимкнути нагрів; за аварії — скинути її |
| Утримання ≥ 700 мс | наступний профіль (1→2→3→1) |
| Натискання + обертання (або обертання після утримання) | редагування температури активного профілю |
| Жало в підставці | нагрів зупиняється, режим STANDBY; після зняття відновлюється, якщо був увімкнений |

Профілі за замовчуванням: 200 / 250 / 300 °C. Після подачі живлення нагрів завжди **вимкнений** — його вмикають кнопкою або командою `HEATER=ON`.

### Режими та індикація

| Режим | Дисплей | LED |
|---|---|---|
| OFF | `0FF` сірим | сірий |
| ON | температура білим | зелений |
| STANDBY | температура синім | синій |
| FAULT | `Err` червоним | червоний, мигання ~2 Гц |

## Захист і коди аварій

Кількість звукових сигналів у серії дорівнює коду аварії (пауза між серіями 1.5 с). Під час аварії нагрів вимкнений.

| Код | Причина | Умова | Скидання |
|---|---|---|---|
| 1 | Обрив термопари | сирий код АЦП > 2500 п'ять періодів поспіль | код АЦП нижче порогу |
| 2 | Перегрів | температура > 480 °C | температура < 430 °C |
| 3 | Розгін | > уставка + 60 °C довше 2 с і без спадання протягом 15 с | температура < уставка + 60 °C |
| 4 | Температура не росте | вихід PID > 90 % і приріст < 20 °C за 30 с | кнопкою |

Скидання виконується коротким натисканням, коли умова скидання вже виконана.

## UART-команди

Рядок закінчується `\n`, регістр не важливий, максимум 64 символи.

| Команда | Дія |
|---|---|
| `HELP` / `?` | список команд |
| `PID?` | поточні kP, kI, kD |
| `KP=` / `KI=` / `KD=` `<число>` | змінити коефіцієнт на льоту |
| `SET=<°C>` | уставка (0…450) |
| `HEATER=ON\|OFF\|1\|0` | нагрів |
| `STATUS` | одноразовий рядок стану |
| `SAVE` | негайно зберегти уставку і PID в EEPROM |
| `SOUND=ON\|OFF\|1\|0` | звук |
| `TONE=ТИП:ЧАСТОТА` | частота сигналу, 0…10000 Гц (0 — вимкнути). Типи: `TEMP`, `CRADLE_ON`, `CRADLE_OFF`, `ENC_ROT`, `ENC_PRESS`, `ENC_HOLD`, `FAULT` |

Кожні 250 мс виводиться телеметрія:

```
SET=250C  TIP=248C  IC1118=26C  |  INA219: I=2100mA V=24010mV P=50.4W  |  VN5E_I=2090mA  PWM=45%  MODE=ON  FLT=0  BUZZER=ON  kP=500.0  kI=1.00  kD=0.00
```

PID за замовчуванням: `kP=500`, `kI=1`, `kD=0`.

## Калібрування

Температура жала:

```
T = TC_SLOPE_C_PER_COUNT · (counts − TC_BIAS_COUNTS) + T_холодного_спаю
```

1. Остудіть жало до кімнатної температури.
2. Порівняйте `TIP` з `IC1118` у телеметрії і підберіть `TC_BIAS_COUNTS` (за замовчуванням 79) у `_00_globals.ino`, щоб значення збігалися.
3. Звірте температуру з зовнішнім термометром на робочих точках, за потреби скоригуйте `TC_SLOPE_C_PER_COUNT` (0.2925).
4. Підберіть PID командами `KP=`, `KI=`, `KD=` і збережіть `SAVE`.

Інші параметри в `_00_globals.ino`: `MAX_HEATER_DUTY_PERCENT` (обмеження потужності, 70 %), `MAX_SETPOINT_C`, `HARD_MAX_TEMP_C`, `OVERSHOOT_*`, `STALL_*`, `INA219_SHUNT_OHMS`.

## Принцип роботи (коротко)

Період ШІМ 20 мс. Останні 1250 мкс періоду нагрівач вимкнений, і в цьому вікні ADS1118 вимірює термопару (без наведень від ключа). Наприкінці періоду в перериванні читається результат, перевіряється обрив, застосовується фільтр викидів (відхилення < 1000 одиниць від останнього прийнятого), рахується температура, виконується PID і виставляється нова шпаруватість (макс. 70 % доступного часу). Усе інше — інтерфейс, захист, UART, дисплей — виконується в головному циклі.

## Відомі зауваження

- Умова захисту з кодом 4 порівнює вихід PID із `MAX_HEATER_DUTY_TICKS × 0.9` (16 875), а вихід обмежений 13 125, тому вона, схоже, не спрацьовує. Варто порівнювати з `MAX_HEATER_DUTY_LIMITED`.
- Шкала ШІМ рахується від `MAX_HEATER_DUTY_TICKS`, тож максимум показує ≈70 %.
- Старий бінарний протокол вимкнений: `SerialReceive()` / `SendStatusPacket()` оголошені, але не реалізовані; частина змінних і функцій (`multiMap2`, `adc_reading`/`deg_c`, `PulsePin`, `idle_temp_c`, `output_override`) не використовується.
- `SET=` по UART змінює поточну уставку, але не змінює температуру активного профілю.

## Безпека

Пристрій керує потужним нагрівачем. Перед першим запуском перевірте захисні функції (обрив термопари, поведінку в підставці), не залишайте увімкнену станцію без нагляду та використовуйте блок живлення з відповідним запасом по струму.
